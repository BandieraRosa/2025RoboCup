# 2025 RoboCup自动分拣机器人——立体仓库赛项

本仓库为针对2025RoboCup立体仓库赛项中的视觉任务设计的项目。该系统能够实时检测视野中的红色或蓝色球体，并通过串口发送识别结果，同时在LCD屏幕上进行可视化调试。

## 主要功能

**实时图像处理**：直接在嵌入式设备上高效处理摄像头捕捉的视频流。

**红蓝双色识别**：能够区分红色和蓝色的目标物体。

**鲁棒的物体检测流程**：

- **颜色分割**：基于可调的颜色、饱和度和亮度阈值，从复杂背景中提取目标颜色区域。
- **形态学处理**：使用开/闭运算有效去除图像噪声、填充物体内部空洞，使目标轮廓更清晰。
- **连通区域分析**：查找并标记所有独立的颜色块。
- **智能筛选**：根据物体的像素面积和宽高比等几何特征，从多个候选目标中筛选出最可能是球体的对象。

**多模式输出**：

- **数据输出**：通过UART串口发送指令（`0x01`代表红色，`0x02`代表蓝色），与主控板通信，指导其在特定阶段的行动。
- **可视化调试**：在LCD屏幕上实时显示处理后的二值图像，并用绿色矩形框标记出识别到的球体，同时在屏幕顶部显示状态信息。

**模块化代码**：除BSP外，包含一个图像处理库 (`image_process.c/.h`)，提供颜色空间转换、几何变换、绘图函数等常用功能，易于复用和扩展。

**高度可配置**：所有关键的图像处理参数（如颜色阈值、物体尺寸等）都以宏定义的形式在头文件中提供，方便用户根据实际环境和目标物进行快速调优。



## 硬件要求

本项目主要针对 **Kendryte K210** SoC 开发，但其核心算法可移植到其他性能相当的嵌入式平台。

- **主控**：搭载 Kendryte K210 SoC 的开发板
- **摄像头**：DVP 接口的摄像头模组
- **显示屏**：SPI 接口的 LCD 屏幕
- **通信**：UART 接口，用于向上位机或其他控制器发送数据



## 项目结构

```
.
├── main.c                  # 主程序入口，包含应用逻辑和图像处理流程控制
├── image_process.c         # 核心图像处理算法库的实现
├── image_process.h         # 图像处理库的头文件和关键参数宏定义
└── BSP/
    ├── CAMERA/             # 摄像头驱动
    ├── KEY/                # 按键驱动
    ├── LCD/                # LCD屏幕驱动
    └── UART/               # UART串口驱动
```

本项目BSP基于正点原子DNK210的例程BSP进行改进，主要修改如下：

- 添加开闭补光灯作为通用摄像头初始化函数之一。
- 使用Port1作为通信端口。
